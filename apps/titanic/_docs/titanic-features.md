# 타이타닉 생존자 예측 데이터셋 명세서 (Titanic Dataset Description)

이 문서는 타이타닉 생존자 예측 머신러닝 모델 구축 및 피처 엔지니어링(Feature Engineering)을 위해 기존 영문 데이터셋 명세를 분석하기 좋게 한글로 정리한 가이드라인입니다.

---

## 1. 데이터셋 개요 (Dataset Overview)

데이터는 크게 두 개의 그룹으로 나누어져 있습니다.

* **학습 데이터셋 (`train.csv`)**
  * 머신러닝 모델을 학습(Build)시키는 데 사용됩니다.
  * 각 승객의 생존 여부 정답(Ground Truth, 레이블)이 포함되어 있습니다.
  * 승객의 성별, 티켓 등급 등의 기본 '피처(Features)'를 기반으로 모델을 학습시키며, 이를 활용해 새로운 피처를 만들어내는 **피처 엔지니어링**을 수행할 수 있습니다.
* **테스트 데이터셋 (`test.csv`)**
  * 학습된 모델이 새로운 데이터에 대해 얼마나 잘 작동하는지 성능을 검증하는 데 사용됩니다.
  * 테스트 데이터셋에는 생존 여부 정답이 포함되어 있지 않습니다.
  * 모델을 이용해 테스트 데이터셋의 각 승객이 타이타닉호 침몰에서 생존했는지 여부를 예측하는 것이 최종 목표입니다.
* **제출 샘플 파일 (`gender_submission.csv`)**
  * 모든 여성 승객만 생존하고 남성 승객은 사망했다고 가정했을 때의 예측 결과 예시 파일입니다. 최종 제출 파일의 형식을 참고하는 용도로 사용됩니다.

## 2. 데이터 사전 (Data Dictionary)

| :--- | :--- | :--- |
| **survival** | 생존 여부 (타겟 변수) | 0 = 사망 (No), 1 = 생존 (Yes) |
| **pclass** | 티켓 등급 (사회·경제적 지위) | 1 = 1등석 (상류층), 2 = 2등석 (중산층), 3 = 3등석 (하류층) |

| **age** | 나이 (세) | 소수점 혹은 정수 (세부 사항 참고) |
| **sibsp** | 타이타닉에 동반한 형제자매 및 배우자 수 | 정수 (동승한 수) |
| **parch** | 타이타닉에 동반한 부모 및 자녀 수 | 정수 (동승한 수) |
| **ticket** | 티켓 번호 | 문자열/숫자 혼합 형태 |

| **embarked** | 승선 항구 (탑승지) | C = 셰르부르(Cherbourg)<br>Q = 퀸즈타운(Queenstown)<br>S = 사우샘프턴(Southampton) |

## 3. 변수별 세부 분석 노트 (Variable Notes)

피처 엔지니어링 시 도메인 지식으로 활용할 수 있는 각 변수의 특이사항입니다.

* **pclass (티켓 등급)**
  * 승객의 **사회·경제적 지위(SES, Socio-Economic Status)**를 나타내는 간접적인 지표입니다. 1등석일수록 상류층, 3등석일수록 하류층에 가깝습니다. 객실의 위치나 구명보트 접근성과도 밀접한 연관이 있을 수 있습니다.
* **age (나이)**
  * 1세 미만 영유아의 경우 나이가 **소수점(분수)**으로 표현됩니다. (예: 0.42세, 0.67세 등)
  * 나이가 정확하지 않고 추정치인 경우 **`xx.5`** 형태로 기록되어 있습니다. (예: 28.5세 등) 데이터 정제나 결측치 처리 시 고려해야 합니다.
* **sibsp (형제자매 / 배우자 수)**
  * 가족 관계 중 수평적인 관계의 동승자 수를 의미합니다.
  * **형제자매(Sibling):** 남동생, 여동생, 의붓형제, 의붓자매를 포함합니다.
  * **배우자(Spouse):** 남편, 아내를 의미합니다. (단, 약혼자나 내연 관계는 이 집계에서 제외되었습니다.)
* **parch (부모 / 자녀 수)**
  * 가족 관계 중 수직적인 관계의 동승자 수를 의미합니다.
  * **부모(Parent):** 어머니, 아버지를 포함합니다.
  * **자녀(Child):** 아들, 딸, 의붓아들, 의붓딸을 포함합니다.
  * *주의 사항:* 일부 어린아이들의 경우 부모 없이 유모(Nanny)하고만 탑승한 경우가 있으며, 이 경우 이 아이들의 `parch` 값은 `0`으로 기록되어 있습니다.
* **가족 규모 피처 생성 팁 (Feature Engineering Tip)**
  * `sibsp`와 `parch`를 더하고 자기 자신(+1)을 더하면 전체 동승 가족 수(`FamilySize`)를 유추할 수 있습니다.
  * 가족이 없이 혼자 탑승했는지 여부(`IsAlone`)를 나타내는 이진 변수(Binary Variable)도 파생할 수 있습니다.
